# 부석증권 · 우리들의 모의투자

**[게임 플레이 →](https://buseok-stock.artful-boar-9093.chatgpt.site)**

ChatGPT 계정으로 로그인하면 가상 투자금 **1,000만 원**으로 시작합니다. 명단의 27명을 모두 반영한 가상 기업 27개와 지수·인버스·레버리지 ETF 4개를 거래합니다.

- 매일 **16:40–23:40 (Asia/Seoul)**, 10분 단일가 시장
- 시장가·지정가, 미체결 취소·장 종료 만료, 수수료, 일일 가격 제한
- 뉴스·업종·변동성·실제 이용자 매수/매도 수요가 가격에 반영
- 서버에 공유 계좌·주문·보유 주식 저장, 종목 검색·관심 종목·차트·포트폴리오·랭킹
- PC·태블릿·모바일 화면 지원

## 거래 규칙

매수와 매도에 각각 0.1% 수수료(원 미만 올림)를 부과합니다. 일일 가격 제한은 전일 종가 대비 ±30%, 호가 단위는 1원입니다. 1회 주문은 1–2,000주, 미체결 주문은 계정당 최대 30건, 분당 주문은 12건까지입니다.

주문은 다음 10분 경계에서 계산한 단일가가 지정가 조건을 만족할 때 전량 체결합니다. FIFO 방식이며 부분 체결은 하지 않습니다. 이용자 주문을 교차시키고 가상 시장조성자가 회차당 순수요 2,000주까지 공급합니다. 시장가 매수는 일일 상한가와 수수료 기준으로 금액을 확보한 뒤 체결 차액을 돌려줍니다. 공매도·신용·세금은 없고 결제는 즉시 처리합니다.

마지막 단일가는 23:40입니다. 이후 남은 주문은 만료되고 확보금과 주식이 반환됩니다. 일일 지수 ETF, -1배 인버스, 2배 레버리지, -2배 인버스는 부석 27 동일 비중 지수의 일일 수익률을 추종하고 일일 비용 0.05%를 반영합니다. 장기 수익률은 단순 배수와 다릅니다. PER·배당수익률 등 기업 지표는 설정값이며 배당금 지급 기능은 없습니다.

종목명은 제공된 이름에 가상 업종명을 붙여 구성했습니다. 기업과 뉴스는 모의투자용 가상 설정이며 실제 인물의 활동·능력·평가와 무관합니다.

## 서버와 배포

프런트엔드: React / Vinext / TypeScript. 서버: Cloudflare Workers + D1(SQLite). 인증: Sites의 ChatGPT 계정 로그인. 실제 플레이 서버는 위 주소이며, GitHub Pages만으로는 서버 계정·공유 주문 기능이 실행되지 않습니다. 비밀번호나 계정 이메일은 게임 DB 또는 랭킹에 저장하지 않고, 사이트별 사용자 ID와 게임용 닉네임을 사용합니다.

`lib/engine.ts`가 결정적 시세 계산과 단일가 정산을 담당하고, SQL 트리거가 확보금·보유량·손익 정합성을 강제합니다. 거래와 예약 상태는 원자적 D1 배치에서 반영됩니다. revision 검증으로 동시 주문/취소 중 읽은 오래된 호가로 정산하는 일을 차단합니다. 요청 키의 고유 제약으로 네트워크 재시도 시 중복 매수도 방지합니다.

시세의 논리적 기준은 항상 서버의 한국 시간 10분 경계입니다. 조회 시 누락된 회차를 시간순으로 복원하므로 방문자가 없어도 이후 거래 결과가 동일합니다. `.github/workflows/market-heartbeat.yml`은 장 시간대에 서버를 주기적으로 호출합니다. GitHub Actions 예약 실행은 지연될 수 있으며, 그때도 서버가 빠진 회차를 정산합니다. 동기화 중에는 신규 주문이 잠시 제한됩니다.

GitHub에는 애플리케이션 소스를 보관합니다. `.openai/hosting.json`의 같은 프로젝트로 Sites 배포 절차를 진행하면 기존 계좌와 데이터가 유지됩니다. 이미 적용한 `drizzle/` 마이그레이션은 수정하지 않고 새 마이그레이션을 추가합니다.

## 개발과 검증

Node.js 24 권장. 의존성은 `pnpm-lock.yaml`에 고정되어 있습니다.

```sh
corepack pnpm install --frozen-lockfile
node node_modules/typescript/bin/tsc --noEmit
node --experimental-strip-types --test tests/market.test.mjs
```

스키마는 `db/schema.ts`, 마이그레이션은 `drizzle/`에 있습니다. 거래 테스트는 Node 내장 SQLite로 실제 마이그레이션·트리거·시장 엔진을 검증합니다. Sites 플러그인의 설치·빌드·배포 도구를 사용합니다. 운영 인증은 플랫폼이 제공하며 임의로 인증 헤더를 신뢰하는 외부 서버에 그대로 배포하면 안 됩니다.
